# 僵尸农场 · 每次启动都声明免费 + 文件校验

## 这一版解决什么

上一版把「本作免费开源 · 请勿购买」印在了标题画面上，但那只挡住了一种偷法。换一个干净的 IPA，
水印就没了；管理器里那份完整声明，转卖的人只要事先打开一次，买家也再看不到。
这一版把这两个口子都补上：**声明每次启动都出现**，**游戏本体按哈希核对**。

## 管理器（Windows / Android）

- **免费开源声明改成每次启动都弹**，不再是「首次运行一次」。卖家预先打开过一次也没用，
  买家一进来就会看到；声明最下面一行直接给出文件校验的结论。
- **新增「文件校验」页**：`touchHLE.exe`、游戏 IPA、管理器自身，官方值与本机实际值并排显示，
  对不上标红。管理器自身那一行只显示、不比对 —— 期望值没法写在被校验的文件里，
  拿它和本文末尾的 SHA-256 对一下就行。
- **启动游戏前再核对一遍**：`touchHLE.exe` 或 IPA 与官方不一致时会弹窗提醒（不阻断 ——
  玩家可能用的是自己编译的版本，管理器不该替他做这个决定）。
- 底部常驻脚注与声明弹窗里都加上了**交流群 QQ 1185712984**。

## 游戏本体

- **touchHLE 现在只运行官方发行版的 IPA。** 启动时算一遍 SHA-256，和编译进去的官方哈希对不上
  就拒绝启动，弹窗写明「这不是官方发行版」并给出官方地址。换包、改图、抹水印不再是改个文件名的事。
- 这是本项目唯一一道**会阻断**的检查。

## 发行包

- 新增 **`校验.bat`**：双击即可核对五个关键文件，只用 Windows 自带的 `certutil`，不联网、不改文件。
- 新增 **`SHA256SUMS.txt`**：包内全部 44 个文件的 SHA-256。

## 升级说明

- **Windows**：整个文件夹替换即可。存档在 `touchHLE\touchHLE_sandbox`，不动它就不会丢。
- **Android**：`versionCode` 6 → 7，签名证书不变（`c2ddca91…4ca6f`），可直接覆盖安装。

## 边界（请照着说，别夸大）

- 这些检查**不是 DRM**。它们让「拿我们的包改一改再卖」变贵、变明显，但拦不住铁了心的人：
  能反编译 touchHLE 的人可以把校验删掉，也能换一个完全不同的包。
- 真正无法伪造的是水印本身和 GitHub 上的哈希 —— 买家照着比对，就能知道手里这份是不是官方的。
- 「签名不匹配」的 Android 提示路径依旧没有用伪造重签包实测过。
- 游戏内容、存档格式均未改动，旧存档可以直接继续用。
