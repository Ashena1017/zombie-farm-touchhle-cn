# 僵尸农场 · 免费开源声明与安卓签名校验

这个项目从一开始就是免费、开源的，官方发布只有 GitHub 这一处。最近发现有店铺在闲鱼上倒卖本项目的整合包，所以我们做了这一版：**不争论版权（游戏本体不归我们，模拟器部分又是允许转售的 MPL-2.0），而是把「免费、开源、官方地址」放进软件本身**，让每个拿到包的人一眼就能看见。

买到倒卖版的人，打开管理器就会看到声明页；我们也在包里放了纯文本说明，并在 README 里写明：**如果你花钱买过这个软件，请申请退款并向平台举报那条商品**。

## 这一版加了什么

**Windows 管理器**

- 标题栏改为「Zombie Farm 游戏管理 · 免费开源」，任务栏与截图里都看得见。
- 每个页签下方常驻一行可点击脚注：唯一官方来源、以及「付费购买请联系退款」。
- 首次运行弹一次「欢迎使用 · 免费开源声明」：官方地址、退款提示、MPL-2.0 与素材版权归属，并显示管理器自身的 SHA-256 前 16 位，方便与本文的校验信息比对。关闭后不再重复；改文案时会按声明版本号重新提示一次。
- 点脚注可随时重新打开这份声明。

**Android 管理器**

- 副标题改为「僵尸农场 · 中文版 · 免费开源」，底部新增不滚动即可看到的常驻脚注，点它可打开完整声明。
- 首次启动同样弹一次声明（升级安装后也会提示一次，之后不再出现）。
- **新增启动时签名自校验**：安装包的签名证书与我们发布版不一致时，会提示「检测到非官方修改版本」并给出官方地址。这拦的是被人改包重签后二次销售的情形；正版不会误报，也不会阻止继续使用。
- `versionCode` 由 `4` 升到 `5`，签名证书与上一版相同，可直接覆盖安装。

**安装包内**

- 压缩包根目录新增 `请勿购买.txt`：免费声明、官方地址、校验方法。
- `使用说明.html` 顶部新增免费声明横幅，文件清单同步更新。

## 使用与升级

- Windows：解压到新目录，运行 `游戏管理.exe`。已有进度请先用旧管理器备份，再在新目录里恢复；保留旧目录，避免覆盖自己的进度。
- Android：可直接覆盖安装（签名一致，`versionCode 4 → 5`）。内置 v29fix IPA，其他版本仍可导入。
- 两端默认夜间模式；发行包不预置任何玩家存档，首次进入游戏后自行创建进度。
- 如果你是因为看到「免费」才找到这里的，那么恭喜——这正是这一版的目的。

## 验证与源码

- 新增探针 `_analysis\_notice_probe.ps1`：在 `%TEMP%` 的发行包副本上连跑三轮——首启弹窗出现、点按钮关闭并写入标记、二次启动不再出现、设置 `ZFR_MANAGER_NO_NOTICE=1` 时抑制且不写标记；并用截图均值亮度确认日夜主题真实切换（44.7 → 227.3）。真实存档全程未参与。
- 重建的 Windows 发行包独立运行 `45.0 s` 通过，无 panic；包内 sandbox 为 0 文件，无运行日志。
- ZIP 为 43 个文件、单一同名顶层目录，`请勿购买.txt` 在根目录；包内管理器 SHA-256 与源码逐字节一致（`101A5A7D528D3AE5…`）。
- Android 已在 MuMu 实机验证：设备上安装包与本地构建逐字节一致；首启弹窗、常驻脚注、关闭后不重复、日夜切换、打开官方地址均正常；签名自校验在正版包上没有误报；`logcat` 无本应用崩溃或 ANR。
- 两端 `touchHLE` 原生程序沿用源码 commit `2a478424b50591360f91790ee760f34b78072987` 的分配器修复；Windows `touchHLE.exe` 为 `28,878,848 B`，SHA-256 `D48D903494AEC412386472637282AA8A1ACC4F0789E1A16921585EE702C1041D`。IPA 仍为 v29fix（`E5951F945D23E88F25D0D1E7DC84E39AB524C566E28460173600BA05423C9DED`）。
