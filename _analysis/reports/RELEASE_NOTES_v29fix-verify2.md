# 僵尸农场 · 非官方 IPA 可以正常启动了

上一版把校验做过头了：只要不是官方那个 IPA 就拒绝启动。**这是错的** —— 用自己的备份、
别的版本、自己调试的包，都是正常需求。这一版放宽。

## 改了什么

- **任何 IPA 都能启动。** 不再比对「你要运行的这个包」的哈希。
- **只盯官方发行版自带的那个 IPA 还在不在。**
  - 它被删掉 → touchHLE 拒绝启动，弹窗说明「官方包不在了」，并给出官方地址。
  - 它还在、只是你自己运行了别的包 → 照常启动，什么都不问。
  - 它还在、但内容被换成别的（同名覆盖）→ 照常启动，但管理器的「文件校验」页会标红。
- **管理器的「文件校验」页改成固定看三样**：`touchHLE.exe`、内置游戏 IPA、管理器自身，
  不再跟着你选哪个包变；下面多一行「当前选择：…」，明确告诉你现在跑的是不是官方包。
- Windows 与 Android 同步；Android `versionCode` 8，签名证书不变，可覆盖安装。

其余不变：免费开源声明仍然每次打开管理器都弹（带 QQ 群 1185712984 和校验结论）、
标题画面水印、`校验.bat`、`SHA256SUMS.txt` 都在。

## 边界

- 这一道**只防「删掉带水印的包」**，防不住「同名覆盖成干净的包」——那种情况只会让
  管理器标红，不会阻止启动。要彻底防，得靠代码签名证书，本项目没有。
- 如果你把官方包挪到别处、只想用自己的 IPA，会被拦住。开发调试可以设
  `ZFR_ALLOW_ANY_IPA=1` 绕过（不写进弹窗，免得教人绕过）。
- Android 侧本轮仍然只做到包级校验，没有在设备上重装实测。
